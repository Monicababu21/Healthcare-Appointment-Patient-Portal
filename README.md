# 🏥 Healthcare Appointment & Patient Portal

A responsive web-based **Healthcare Appointment & Patient Portal** designed to provide a simple interface for patient registration, appointment management, and access to basic health information.

The project is developed using **HTML5, CSS3, and Bootstrap 5**, with a focus on responsive design and an easy-to-use healthcare interface.

---

## 📌 Project Overview

The Healthcare Appointment & Patient Portal allows patients to enter their personal and medical information, select a department and doctor, and schedule an appointment.

The portal also provides sections for:

* Patient Registration
* Appointment Management
* Health Information
* Healthcare Services
* Technologies Used
* Responsive Navigation

---

## ✨ Features

### 👤 Patient Registration

The registration form collects:

* Patient Name
* Email Address
* Mobile Number
* Date of Birth
* Gender
* Blood Group
* Department
* Doctor
* Appointment Date
* Appointment Time
* Address
* Symptoms / Health Issues

### 📅 Appointment Management

Patients can provide appointment details including:

* Department
* Doctor
* Date
* Time
* Patient information
* Symptoms

### 🩺 Health Information

A dedicated section provides basic health-related information in an organized and readable format.

### 🏥 Healthcare Services

The portal includes a services section representing different healthcare facilities and services.

### 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile devices

Bootstrap's responsive grid and components are used to improve the layout on different screen sizes.
